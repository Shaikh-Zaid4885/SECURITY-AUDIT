# 🔒 Security Audit – Botium Toys

## Overview
This repository contains a security audit conducted for Botium Toys as part of a cybersecurity risk assessment exercise. The audit evaluates the organization's current security controls, compliance requirements, and overall security posture based on industry best practices and regulatory standards.

## Objectives
- Assess existing security controls and compliance measures.
- Identify security gaps and areas of risk.
- Evaluate adherence to PCI DSS, GDPR, and SOC standards.
- Provide recommendations to improve the organization's security posture.

## Scope
The audit covers the following areas:

- Asset Management
- Access Control
- Password Security
- Network Security
- Data Protection and Encryption
- Backup and Disaster Recovery
- Legacy System Management
- Physical Security Controls
- Regulatory Compliance

## Risk Assessment Summary
The organization received a risk score of **8/10 (High Risk)** due to:

- Inadequate asset management
- Lack of encryption for sensitive customer data
- Absence of an Intrusion Detection System (IDS)
- Weak password controls
- Missing disaster recovery and backup procedures
- Insufficient implementation of least privilege and separation of duties

## Key Recommendations
- Implement Role-Based Access Control (RBAC) and Least Privilege.
- Deploy an Intrusion Detection System (IDS).
- Encrypt sensitive customer and payment data.
- Implement Multi-Factor Authentication (MFA).
- Establish automated backups and a Disaster Recovery Plan.
- Deploy a centralized password management solution.
- Conduct regular security awareness training.
- Maintain an accurate inventory of organizational assets.
